# Instructivo Tecman para sucursal

## Objetivo

Tecman es el canal oficial para informar problemas de mantenimiento. Todo reclamo debe cargarse como ticket para que quede registrado, asignado y con seguimiento.

## Sucursales del piloto

El piloto inicial se realiza solo con estas sucursales:

- Sucursal 195.
- Sucursal 213.
- Sucursal 014.
- Sucursal 211.
- Sucursal 036.

## Como ingresar

1. Entrar al portal de Tecman.
2. Seleccionar el acceso de Sucursal.
3. Ingresar usuario y clave de la sucursal.
4. Revisar el panel principal.

## Como cargar un ticket

1. Entrar en Nuevo ticket.
2. Elegir categoria del problema.
3. Elegir subcategoria.
4. Completar descripcion clara del problema.
5. Indicar prioridad segun urgencia real.
6. Adjuntar fotos si ayudan a entender el problema.
7. Enviar el ticket.

## Que debe tener una buena descripcion

- Lugar exacto: salon, deposito, caja, probador, vidriera, bano, techo, tablero, etc.
- Que esta pasando.
- Desde cuando ocurre.
- Si afecta ventas, seguridad, mercaderia o apertura del local.
- Si ya se intento alguna solucion.

Ejemplo:

Hay perdida de agua en bano de clientes, debajo de la mochila del inodoro. Empezo hoy a la mañana. Se esta juntando agua en el piso y puede generar riesgo de caida.

## Seguimiento del ticket

- La sucursal puede ver el estado del ticket desde su panel.
- Si administracion responde, la novedad queda visible en Tecman.
- Si se piden mas datos o fotos, la sucursal debe responder desde el ticket.
- No se debe abrir otro ticket por el mismo problema salvo que sea un caso distinto.

## Estados mas comunes

- Nuevo: ticket cargado, pendiente de revision.
- Abierto: administracion ya lo vio.
- En progreso: hay responsable trabajando el caso.
- Pendiente: falta informacion, materiales, visita o definicion.
- Resuelto: el proveedor o equipo marco el trabajo como terminado.
- Cerrado: administracion cerro definitivamente el caso.

## Reglas durante el piloto

- Cargar solo problemas reales.
- No usar WhatsApp como reemplazo del ticket.
- Si el problema empeora, agregar comentario o nuevo dato al ticket existente.
- Adjuntar fotos cuando el problema sea visible.
- Confirmar si el trabajo quedo bien resuelto cuando corresponda.

## Cuando usar prioridad urgente

Usar prioridad urgente solo si hay:

- Riesgo para personas.
- Riesgo electrico.
- Perdida de agua importante.
- Local sin poder operar.
- Mercaderia en riesgo.
- Problema que afecta apertura o cierre del local.

## Contacto operativo

Durante el piloto, cualquier duda de uso se informa a administracion de mantenimiento para ajustar el proceso.
